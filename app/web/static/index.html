System Architecture & Cloud vs. Local Boundary

VisionGuard AI uses a decoupled pipeline where deep learning inference executes on the server while video capture runs client-side inside standard web browsers:

🌐 Web Live Demo Mode

  • Video Capture: Client-side HTML5 WebRTC stream
  • Inference: InsightFace Buffalo_L ONNX Engine
  • Robot Telemetry: High-precision 2D Canvas Simulation
  • Network: REST & Low-Latency WebSocket

💻 Native Desktop App Mode

  • Video Capture: Direct OpenCV OS Webcam Capture
  • Microcontroller: PySerial UART to Arduino/ESP32
  • UI Framework: CustomTkinter (Dark Theme)
  • Packaging: Standalone Windows Executable
